## Overview

**IRON & DUST** is a responsive, visually driven website created for a fictional custom motorcycle workshop.

The project explores how strong typography, atmospheric imagery, and carefully designed motion can turn a traditional business website into a memorable digital experience.

The visual direction combines industrial textures, dark surfaces, warm copper accents, and an editorial approach to layout.

**Project type:** Personal portfolio concept\
**Role:** Web development and implementation\
**Status:** Completed locally — public deployment pending

## Design Philosophy

*Built different. Ride your own way.*

The interface takes inspiration from the world of custom motorcycles: precision, individuality, craftsmanship, and mechanical character.

The design focuses on three principles:

- **Visual impact** — bold typography, cinematic imagery, and deliberate composition.
- **Purposeful motion** — animation that supports the story without distracting from the content.
- **Usability** — responsive layouts, accessible interactions, and clear navigation.

## Features

**Cinematic Hero**

An animated introduction with layered typography, image transitions, and staggered content reveals.

**Scroll-Driven Reveals**

Sections, images, and content elements appear progressively as visitors explore the page.

**Selected Builds Gallery**

An interactive showcase of three fictional motorcycle builds:

- The Phantom — Café Racer
- Dust Runner — Scrambler
- Blackline — Street Custom

**Responsive Experience**

Layouts and imagery adapted for desktop, tablet, and mobile screens.

**Accessible Interactions**

Keyboard-conscious interactive elements and support for reduced-motion preferences.

**Contact Section**

A demonstration contact interface designed to illustrate the intended user experience. It is not connected to a live business inquiry service.

## Getting Started

**Requirements:** Node.js and npm.

Clone the repository:
```bash
git clone https://github.com/Kybrik32/Iron_and_dust.git
```

Open the project directory:
```bash
cd Iron_and_dust
```

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Open the local address displayed in the terminal.

### Production Build
```bash
npm run build
```

The production-ready files are generated in the `dist` directory.
